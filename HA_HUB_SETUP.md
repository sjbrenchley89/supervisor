# Home Assistant Hub Connection Setup

This repository is configured to connect to a Home Assistant Hub for integration testing and configuration management.

## Quick Start

### 1. Local Development Setup

1. Copy the environment template file:
   ```bash
   cp .env.example .env
   ```

2. Edit `.env` and add your credentials:
   ```env
   HA_HUB_URL=http://192.168.1.121:8123
   HA_HUB_TOKEN=your_long_lived_access_token_here
   ```

3. The `.env` file is **gitignored** and will never be committed to the repository.

### 2. Getting Your Home Assistant Token

1. Open your Home Assistant instance at `http://192.168.1.121:8123`
2. Click your user icon (bottom left) → **User profile**
3. Scroll to **Long-Lived Access Tokens**
4. Click **Create Token**
5. Give it a name like "Claude Code Development"
6. Copy the token immediately (you won't be able to see it again)
7. Paste it in your `.env` file

### 3. Verifying the Connection

Test your connection by running:
```bash
python -c "from supervisor.ha_hub_connection import ha_hub_config; import asyncio; print(asyncio.run(ha_hub_config.test_connection()))"
```

## Configuration Options

### Environment Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `HA_HUB_URL` | Home Assistant Hub URL | `http://192.168.1.121:8123` |
| `HA_HUB_TOKEN` | Long-lived access token | (generated by Home Assistant) |

### Python Usage

```python
from supervisor.ha_hub_connection import ha_hub_config

# Check if configured
if ha_hub_config.is_configured:
    print(f"Connected to: {ha_hub_config.url}")

# Validate configuration
try:
    ha_hub_config.validate()
except HassioError as e:
    print(f"Configuration error: {e}")

# Test connection
is_connected = await ha_hub_config.test_connection()
```

## CI/CD Setup (GitHub Actions)

For continuous integration, configure GitHub secrets:

1. Go to your repository settings
2. Navigate to **Secrets and variables** → **Actions**
3. Create two new repository secrets:
   - `HA_HUB_URL`: Your Home Assistant Hub URL
   - `HA_HUB_TOKEN`: Your long-lived access token

Then in your GitHub Actions workflow:
```yaml
env:
  HA_HUB_URL: ${{ secrets.HA_HUB_URL }}
  HA_HUB_TOKEN: ${{ secrets.HA_HUB_TOKEN }}
```

## Security Notes

- **Never commit `.env` file** - it's already in `.gitignore`
- **Rotate tokens regularly** - delete old tokens from Home Assistant
- **Use different tokens** for different environments (dev, testing, production)
- **Keep tokens secret** - treat them like passwords

## Troubleshooting

### Connection Test Fails

1. Verify the Hub URL is correct and accessible
2. Check that the token hasn't expired
3. Ensure your machine can reach the Home Assistant instance
4. Check Home Assistant logs for authentication errors

### Token Issues

- If your token expires, generate a new one from the Home Assistant user profile
- Old tokens automatically expire after 1 year (configurable in Home Assistant)

## Integration Testing

This connection is used for:
- Testing integrations with Home Assistant
- Configuration validation
- Data synchronization
- Automated testing with a real Home Assistant instance

For integration tests, use `ha_hub_config` to get the connection details:
```python
import pytest
from supervisor.ha_hub_connection import ha_hub_config

@pytest.mark.skipif(not ha_hub_config.is_configured, reason="HA Hub not configured")
async def test_hub_connection():
    assert await ha_hub_config.test_connection()
```
